# Summarize Architecture Impact

Create a review-ready briefing for the architect and product owner describing how a proposed change affects system structure and data flows. The workflow captures the initiative context, analyzes touchpoints with `code_tools`, inspects the 1C4D5 diagrams, and assembles an evidence-backed summary.

- **Input:** Feature/initiative details, business drivers, constraints
- **Process:** code_tools architecture review → data flow assessment → documentation plan → stakeholder summary
- **Output:** Markdown brief saved to `{output_folder}/1c4d5/architecture-impact-<date>.md`
- **Follow-up:** Feed recommended actions into backlog, and trigger diagram updates or validations as required
